Hooks —  автоматизації в agent loop
Hooks — це скрипти, які запускаються автоматично в конкретні моменти життєвого циклу Claude Code. На відміну від інструкцій в CLAUDE.md, які є "рекомендаціями" для моделі (і можуть бути проігноровані), хуки гарантовано виконуються. Це ключова різниця: якщо ви напишете в CLAUDE.md "не модифікуй .env файли" — Claude, скоріш за все, послухає. Якщо ви налаштуєте PreToolUse hook, що блокує запис в .env — він заблокує завжди.
Хуки не використовують токени і не залежать від "уваги" моделі. Це звичайні shell-скрипти або HTTP-виклики, що працюють поза LLM.

{
  "session_id": "2d6a1e4d-6...",
  "transcript_path": "/Users/sg/...",
  "hook_event_name": "PreToolUse",
  "tool_name": "Read",
  "tool_input": {
    "file_path": "/code/queries/.env"
  }
}

Events:

// PreToolUse -  Може заблокувати дію, модифікувати вхідні параметри або додати контекст для Claude. Matcher фільтрує по назві інструменту: Bash, Edit, Write, Read, Glob, Grep, WebFetch, MCP tools тощо.
// PostToolUse - Ідеальний для автоформатування, логування, пост-валідації. Не може скасувати дію (вона вже відбулась).
// PostToolUseFailure - спрацьовує при помилці інструменту, дозволяє додати корисний контекст для Claude.
// UserPromptSubmit - при відправці промпту користувачем. Можна валідувати або трансформувати промпт.
// Stop - коли Claude завершує відповідь.
// SessionStart / SessionEnd — старт та завершення сесії.
// SubagentStart / SubagentStop — при запуску/завершенні subagent'ів.


Handler:

// Command (type: "command") — shell-скрипт. Найпростіший і найчастіший тип. Отримує JSON на stdin, виводить рішення на stdout.
// HTTP (type: "http") — надсилає POST-запит на вказану URL. Для інтеграції з зовнішніми сервісами.
// Prompt (type: "prompt") — надсилає промпт до швидкої моделі Claude (Haiku) для семантичної оцінки. Наприклад: "чи торкається цей код логіки авторизації?" — те, що складно виразити через regex.
// Agent (type: "agent") — запускає subagent з доступом до інструментів (Read, Grep, Glob) для глибокої верифікації. Найважчий тип, для серйозних перевірок на кшталт "чи всі змінені файли мають відповідні тести".
